<h2 align="left">🚧 In Progress</h2>

### [CinemaSystem](https://github.com/ValeriaKarpachova/CinemaSystem) &nbsp;<img src="assets/in-progress.svg" alt="Status: in development" height="60" valign="middle" />

> A cinema booking platform — built to explore server-side Blazor and real-time features.

<p align="center">
  <img src="assets/cinema-system.png" alt="CinemaSystem screenshot" width="100%" />
</p>

- 🛠️ Admin panel — full CRUD, auto seat-grid generation, schedule conflict detection
- 🔎 Search & filtering — movies, sessions, tickets, all at the query level (LINQ)
- 📊 Analytics — revenue, occupancy, daily totals via hand-written SQL (Dapper, window functions)
- 🎟️ Customer booking (in progress) — interactive seat map, real-time locking via SignalR, no double-booking
